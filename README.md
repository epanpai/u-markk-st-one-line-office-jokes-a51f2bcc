## The entry

> My calendar is so full of meetings about meetings that my actual job now fits in the lunch break.

A one-line office joke: a concrete detail (a calendar full of meetings about meetings) with the punchline landing on the last few words — the actual job now fits in the lunch break.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–199 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
